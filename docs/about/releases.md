# Releases

All stscale releases are available on the [GitHub release page](https://github.com/tomiwebpro/stealthscale/releases). Those
releases are available as binaries for various platforms and architectures, packages for Debian based systems and source
code archives. Container images are available on [Docker Hub](https://hub.docker.com/r/stscale/stscale) and
[GitHub Container Registry](https://github.com/tomiwebpro/stealthscale/pkgs/container/stscale).

An Atom/RSS feed of stscale releases is available [here](https://github.com/tomiwebpro/stealthscale/releases.atom).

See the "announcements" channel on our [Discord server](https://discord.gg/c84AZQhmpx) for news about stscale.
