# Web interfaces for stscale

!!! warning "Community contributions"

    This page contains community contributions. The projects listed here are not
    maintained by the stscale authors and are written by community members.

StealthScale doesn't provide a built-in web interface but users may pick one from the available options.

- [stscale-ui](https://github.com/gurucomputing/stscale-ui) - A web frontend for the stscale Tailscale-compatible
  coordination server
- [StealthScaleUi](https://github.com/simcu/stscale-ui) - A static stscale admin ui, no backend environment required
- [Headplane](https://github.com/tale/headplane) - An advanced Tailscale inspired frontend for stscale
- [stscale-admin](https://github.com/GoodiesHQ/stscale-admin) - StealthScale-Admin is meant to be a simple, modern web
  interface for stscale
- [ouroboros](https://github.com/yellowsink/ouroboros) - Ouroboros is designed for users to manage their own devices,
  rather than for admins
- [unraid-stscale-admin](https://github.com/ich777/unraid-stscale-admin) - A simple stscale admin UI for Unraid,
  it offers Local (`docker exec`) and API Mode
- [stscale-console](https://github.com/rickli-cloud/stscale-console) - WebAssembly-based client supporting SSH, VNC
  and RDP with optional self-service capabilities
- [stscale-piying](https://github.com/wszgrcy/stscale-piying) - stscale web ui, support visual ACL configuration
- [HeadControl](https://github.com/ahmadzip/HeadControl) - Minimal StealthScale admin dashboard, built with Go and HTMX
- [StealthScale Manager](https://github.com/hkdone/headscalemanager) - StealthScale UI for Android
- [StealthScale UI](https://github.com/MunMunMiao/stscale-ui) - StealthScale UI online and Self-hosting
- [StealthScale Panel](https://github.com/stscale-panel/panel) - A modern StealthScale management panel with a clean,
  network-operations-focused UI

You can ask for support on our [Discord server](https://discord.gg/c84AZQhmpx) in the "web-interfaces" channel.
